** About
:PROPERTIES:
:CUSTOM_ID: about
:END:

#+begin_quote
/Yee(t) (You)Tube/
#+end_quote

This package provides the ability to scrape YouTube, with the results
displayed in a tabulated list.

Core features include:

- Executing queries on YouTube
- Playing & Downloading video(s)
- Pagination for loading more results
- Popup menus for quick access to all commands, via [[https://elpa.gnu.org/packages/keymap-popup.html][keymap-popup]]
- Org-link integration for videos & playlists
- A standalone, minimalist yt-dlp wrapper

/This package does not use Invidious or YouTube's API, just parses
html & json./

** Installation
:PROPERTIES:
:CUSTOM_ID: installation
:END:
/YeeTube is available via [[https://melpa.org/#/yeetube][MELPA]]/

Example using =use-package=

#+begin_src emacs-lisp
(use-package yeetube
  :ensure t
  :bind ("C-c y" . #'yeetube))
#+end_src

** Usage
:PROPERTIES:
:CUSTOM_ID: usage
:END:

- =M-x yeetube= opens the popup menu with search, download and settings
- =M-x yeetube-search= to search directly
- In the results buffer, press =h= to see all available keybindings

Settings like results limit, video quality, download directory and
audio format live in a settings submenu: press =o= (in the results
buffer or inside the popup) to enter it.  Each entry shows its
current per-buffer value inline and the menu stays open while you
adjust values; =q= returns to the main popup.

** Configuration
:PROPERTIES:
:CUSTOM_ID: configuration
:END:
*** Media Player
:PROPERTIES:
:CUSTOM_ID: media-player
:END:
By default =yeetube-play-function= is set to =yeetube-mpv-play=, you can
use [[https://github.com/kljohann/mpv.el][mpv.el]],
[[https://www.gnu.org/software/emms/][GNU/Emms]] or other similar
packages like so:

#+begin_src emacs-lisp
(setf yeetube-play-function #'emms-play-url)
#+end_src

Make sure that the media player of your choice can directly play
youtube urls.

*** Thumbnails
:PROPERTIES:
:CUSTOM_ID: thumbnails
:END:
Disable thumbnails:

#+begin_src emacs-lisp
(setf yeetube-display-thumbnails-p nil)
#+end_src

*** Apply Filters
:PROPERTIES:
:CUSTOM_ID: apply-filters
:END:
To filter the search results based on a specific criterion, you can
modify the =yeetube-youtube-filter= value to your preferred option.

For example:

#+begin_src emacs-lisp
(setf yeetube-youtube-filter "Views")
#+end_src

This will filter & sort the search results according to the number of views.

*** Results Limit
:PROPERTIES:
:CUSTOM_ID: results-limit
:END:
By default, yeetube fetches 20 results per search.  You can change this:

#+begin_src emacs-lisp
(setf yeetube-results-limit 50)
#+end_src

You can also change it per-buffer via the settings submenu (=o= then
=l=).  When the limit exceeds results on one page, additional pages
are fetched automatically.

*** Tor & torsocks support
:PROPERTIES:
:CUSTOM_ID: tor-torsocks-support
:END:
For enhanced privacy, using tor & torsocks:

#+begin_src emacs-lisp
(setf yeetube-enable-tor t)
#+end_src

You can also toggle torsocks for mpv per-buffer from the settings
submenu (=o= then =t=).

It's recommended to disable thumbnail support to improve performance
when using tor.

Yeetube is configured to use tor via port 9050.

*** Org links
:PROPERTIES:
:CUSTOM_ID: org-links
:END:
The optional =yeetube-ol= module adds the =yt-video:= and
=yt-playlist:= org-link types: store a link to the entry at point
with =org-store-link=, follow it to play the video (or open the
playlist), and export it as a regular YouTube URL.  To activate:

#+begin_src emacs-lisp
(with-eval-after-load 'org (require 'yeetube-ol))
#+end_src

** Development
:PROPERTIES:
:CUSTOM_ID: development
:END:
The repository ships a Nix flake providing Emacs with all
dependencies.  =make compile=, =make test= and =make lint= re-enter
themselves through =nix develop= when =nix= is available; =make dev=
runs all three.  =nix flake check= runs the test suite as a Nix
check.
